# Banking Consumer Complaint Analysis

This project analyses written banking customer complaints using Natural Language Processing (NLP).

## Methods
- Bag-of-Words
- TF-IDF
- Latent Dirichlet Allocation (LDA)
- Latent Semantic Analysis (LSA)

## Tools
- Python
- pandas
- scikit-learn
- Gensim
- matplotlib

## Dataset
Banking Consumer Complaint Analysis dataset from Kaggle.

A reproducible sample of up to 3,000 complaints was selected for the analysis.

## Project
The Jupyter Notebook contains the data preparation, text cleaning, vectorisation, topic extraction and visualisation steps.
